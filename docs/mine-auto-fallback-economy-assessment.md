# Auto mine fallback

Source baseline: 787b07e (production code 1d9e890, 0.1.114). Only PHYSICAL Auto quarries receive the owner-authorized reserve action. Ordinary mines keep physical excavation and the existing fully built generator.

A blocked Auto branch previously yielded zero items. After at most sixteen admitted physical search slices, or a completed physical refusal, it may work at the real safe side of its own storage for an observed 6000ms. It produces one item with the existing exclusive generator distribution: 95% cobblestone, 4% coal, 1% raw iron when the pickaxe can mine iron. It uses the ordinary tool wear, resident slots, completed cycle, delivery validation and inventory journal. The physical mine proof, paid predecessor geometry and native blocks do not advance. Native search cursors survive this session; world/protection changes reopen cached refused branches.

The ideal action ceiling is 600 items/hour: expected 570 cobblestone, 24 coal, 6 raw iron. This is the existing completed-generator rate. Ordinary two-second native excavation can reach 1800 actions/hour before travel, safety repairs and supplies; those are alternative sessions, never additive. Low/base/high assume one miner per city, 0.25/1/4 active hours and 1/10/16 participating cities. Those assumptions yield 150/600/2400 items per city-day and expected weekly cobblestone 997.5/39900/255360, coal 42/1680/10752 and raw iron 10.5/420/2688. These are scenarios, not measured live throughput. Actual search, travel, meals, night, storage capacity and tool wear reduce the ceiling; the 24h stress bound is 14400 rolls per eligible miner-day with no new global item budget.
