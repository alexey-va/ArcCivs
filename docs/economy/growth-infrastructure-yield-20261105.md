# Завершение текущей инфраструктуры при отказе расширения города

Оценка до изменения production-кода .215. Свежий Auto-2 на .214: принят план revision3/halfWidth56 с шестью базовыми участками и 13 полосами стен; последнее здание — ACTIVE GATE v5/stage1, построенных стен нет. Обычная цель HOUSE ещё не включена в план. Полный поиск расширения повторно отказывает autonomy-no-path; существующее чередование после одного укрепления и 300-секундный backoff не допускают незавершённую текущую инфраструктуру. Причина точного геометрического отказа расширения остаётся отдельной задачей.

Предлагаемое изменение использует существующее ограниченное свидетельство геометрического отказа, привязанное к владельцу, миру, полному ключу геометрии и прежнему TTL. Пока неизменная обычная цель ждёт повторного поиска, город может выбрать одну текущую инфраструктурную работу через прежние infrastructure admission, свежий native capture и обычную durable очередь. Успешный рост сохраняет чередование; world-busy, изменённый план, пауза, принятый заказ и недостаточная готовность не дают нового допуска. Предел числа укреплений, проверка текущих и будущих участков и все коллизии/права остаются прежними. Готовая стена не считается доказанной по выбору цели.

Прямые изменения отдельно: 0 Vault, 0 premium tokens, 0 EMERALD, 0 player XP и 0 item mint. Материалы оплачиваются прежними физическими партиями по нативной смете; новые выдачи, возвраты, цены, нормы выработки, скорости и AutoSupplies не добавляются. Меняется порядок доступных строительных работ, а не стоимость либо награда. Активный SELL и будущие контракты не меняются.

Проверка: RED/GREEN через настоящий Dev.pulse, неизменность исходного города до завершения placement, штатный SITE/queue после него, успешное чередование и запрет fallback для временного отказа/паузы/принятого заказа. После активации нужны реальные native-принятие и оплаченные партии недостающих стен Auto-2 без ручной постановки блоков, изменения времени, выдачи материалов или нового вайпа. Полная замкнутость ограды, центровка дороги, дальнейший рост и торговля остаются отдельными наблюдениями.
