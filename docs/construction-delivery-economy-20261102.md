# Construction delivery and full receiver recovery — 0.1.183

A full courier warehouse prevented construction delivery despite free builder storage and existing native surplus. Construction can now use the same durable direct-input cargo route as other legal destinations. It requires current paid construction, a legal builder HUT, the current remaining bill, preserved source/craft reserves, native destination room and real pickup/dropoff arrival. Native item debit/bag credit/delivery remain in the existing receipt owner. Already carried cargo remains deliverable if its order disappears. Ordinary production inputs keep their advertised-output restriction; construction uses only sources already eligible for normal surplus collection, including incidental materials.

Before/after direct amounts stay separately 0 Vault, 0 premium tokens and 0 player XP. Existing COBBLESTONE is modeled as transfer, never mint: full-warehouse sensitivity is 0 before and up to64 existing units per admitted direct trip after, at assumed0/1/16 trips per settlement-day and1/7/16 settlements. Actual trips are bounded by the remaining bill, in-transit counts, native surplus, reserves, bag capacity and destination room. This is not a throughput measurement. DIRT and ANDESITE use the same existing-item conservation; no sale value or currency exchange is inferred. Builder payment still uses the exact existing bill once. Source drop tables, recipe rates, supply caps and rewards stay unchanged.

A full old control marker can select an existing reachable interior AIR location rather than repeatedly target a full authored barrel. Exact27-slot contents/metadata are preserved, other authored containers remain, and only the old empty marker retires. Cancellation of a blocked intent is metadata-only and requires its old control to remain authoritative and the previously existing receiver to match; newly staged AIR receivers are not abandoned.

Current SELL and planned SELL-to-contract remain separate flows. New gate profile raw-material changes are assessed in gate-refit-economy-20261101.json; oldV2receipts retain their original recipe. Native delivery, paid construction commits, control recovery and client acceptance are recorded separately after activation.
